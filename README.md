# Habit Tracker

API-сервис для формирования полезных привычек по мотивам книги «Атомные привычки».

## Стек
- Python
- Django
- Django REST Framework
- PostgreSQL
- Celery
- Redis
- Telegram Bot API

## Возможности
- регистрация и авторизация;
- создание привычек;
- публичные привычки;
- напоминания в Telegram;
- статистика выполнения.
